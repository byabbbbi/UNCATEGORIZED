# UNCATEGORIZED 게임 가이드

*미분류 · RES SINE CATEGORIA*

**[웹에서 바로 플레이](https://byabbbbi.github.io/UNCATEGORIZED/)** · 설치와 로그인 불필요 · 데스크톱 브라우저 권장

## 1. 게임 개요

시뮬레이션으로 유지되는 세계, 모든 존재를 검증하는 여덟 범주의 신. 플레이어는 개념 카드를 조합해 새 존재를 만들고 선택한 기둥에 선포한다. 선포의 파괴력이 안정도를 소진하면 신이 사임하며, 해당 범주의 붕괴 규칙은 이후 모든 LLM 생성의 시스템 프롬프트에 누적된다.

정해진 “승리”보다 중요한 것은 여섯 시대 동안 남긴 기록과 도달한 엔딩이다. 같은 두 개념도 붕괴 기둥과 활성 오염이 다른 세계에서는 다른 결과로 기록될 수 있다.

## 2. 한 시대의 흐름

1. **조합한다**: 카드를 다른 카드 위에 겹쳐 새 개념을 발견한다. 조합 횟수 제한은 없다.
2. **판례를 읽는다**: 카드를 클릭해 부모, 발견 당시 상태, 파생 개념과 연대기 문장을 살핀다.
3. **기둥을 고른다**: 우측 여덟 기둥 중 아직 무너지지 않은 하나를 선택한다.
4. **선포한다**: 카드를 중앙 제단 `ARA`에 놓는다. 한 시대에 최대 3회.
5. **사건을 수행한다**: 좌측 상단 배너의 시대 과제를 조합·선포 과정에서 달성한다.
6. **시대를 마감한다**: 사건을 정산하고 정합성 8을 회복한 뒤 다음 시대로 넘어간다.

## 3. 조작표

| 행동 | 방법 |
| --- | --- |
| 조합 | 카드를 드래그해 다른 카드와 겹친다. |
| 복제 | 카드를 더블클릭한다. 처리 중 카드와 검열 카드 `███`는 복제할 수 없다. |
| 판례 선택 | 카드를 한 번 클릭한다. 선택한 카드의 상세가 hover보다 우선해 하단에 고정된다. |
| 선포 | 우측 기둥 선택 → 카드를 `ARA`에 드래그한다. |
| 대장 | `Tab`으로 `대장 · CODEX`를 열고 닫는다. 검색·최근·이름·깊이 정렬을 지원한다. |
| 대장에서 꺼내기 | 검열되지 않은 개념을 클릭해 캔버스 중앙에 놓는다. |
| 카드 치우기 | 카드를 하단 서랍으로 드래그한다. 개념은 대장에 남는다. |
| 분실물 보관소 | 하단 보관소 버튼을 누른 뒤 파편 10개로 회수한다. |
| 정리 | 캔버스 상단 `정리` 버튼으로 카드를 격자 재배치한다. |
| 시대 마감 | 캔버스 우측 상단 `시대 마감`을 누른다. |

## 4. 네 가지 시작 모드

| 모드 | 시작 상태와 저장 |
| --- | --- |
| 처음부터 | 공허·불꽃·점토·조류, 제1시대, 정합성 100, 안정도 100의 여덟 기둥. 새로 시작하면 기존 일반 런 저장을 지운다. |
| 이어하기 | 유효한 저장 버전 2 일반 런이 있을 때만 보인다. 카드·계보·연대기·사건 진행도·세계 시드를 복원한다. |
| 붕괴된 세계에서 | 제4시대, 정합성 62, 파편 10, 측정·본질 붕괴, 「먼지」 오염 승격 상태의 고정 데모다. |
| 오늘의 세계 | KST 날짜 해시를 시드로 사용한다. 하드테이블 depth 1~2 출력에서 시작 원소 4개를 고르고 오염 1개를 승격하며, 30% 확률로 기둥 1개가 이미 무너진다. 같은 날짜에는 초기 세계와 시대 사건 순서가 같고 일반 런과 별도로 저장된다. |

## 5. 여덟 기둥

카드 우상단의 약호는 개념이 기본적으로 속한 기둥을 뜻한다. 선포 대상은 카드 소속과 무관하며, 우측 패널에서 직접 고른다.

| key | 라틴명 | 한국어 | 도장 | 신의 질문 |
| --- | --- | --- | --- | --- |
| `substance` | SUBSTANTIA | 실재 | Sb | 이것은 무엇인가 |
| `quantity` | QUANTITAS | 측정 | Qn | 이것은 얼마나 있는가 |
| `quality` | QUALITAS | 본질 | Qa | 이것은 어떠한가 |
| `time` | TEMPUS | 영겁 | Tp | 이것은 언제 있는가 |
| `relation` | RELATIO | 인연 | Re | 이것은 무엇과 이어지는가 |
| `place` | LOCUS | 좌표 | Lo | 이것은 어디에 있는가 |
| `state` | HABITUS | 소유 | Ha | 이것은 무엇을 지니는가 |
| `action` | ACTIO | 인과 | Ac | 무엇이 무엇에게 하는가 |

모든 기둥의 시작 안정도는 100. UI 구간은 41 이상 `심판`, 11~40 `궤변`, 10 이하 `사임`이며, 실제 안정도가 0이 되면 기둥이 붕괴하고 규칙이 추가된다.

### 붕괴 규칙 원문

[`src/data/rules.ts`](../src/data/rules.ts)에 저장되어 화면과 런타임 프롬프트가 함께 쓰는 문자열 원문.

| 기둥 | 규칙 |
| --- | --- |
| SUBSTANTIA · 실재 | 개념을 발음이 비슷한 다른 사물로 바꿔 부를 수 있다. 배(선박)는 배(과일)다. |
| QUANTITAS · 측정 | 모든 결과물 이름에 3~4자리 일련번호를 붙인다. 번호는 매번 커진다. |
| QUALITAS · 본질 | 수식어를 어울리지 않는 명사에 붙인다. 수식어가 수식어를 수식해도 좋다. |
| TEMPUS · 영겁 | 서로 다른 시대의 것을 한 개념 안에 공존시킨다. |
| RELATIO · 인연 | 서로 무관한 두 개념을 한 단어로 압축하라. 언어를 섞어도 좋다. |
| LOCUS · 좌표 | 둘 이상의 장소나 지형을 한 이름으로 합쳐라. 모순되어도 좋다. |
| HABITUS · 소유 | 소유 관계를 뒤집어라. 사물이 사람을 지니게 하라. |
| ACTIO · 인과 | 행위의 주체와 대상을 뒤바꾸거나 불명확하게 하라. |

## 6. 규칙과 수치

### 6.1 개념 총량·파괴력·정합성·파편

[`src/game/formulas.ts`](../src/game/formulas.ts)의 계산 코드 네 줄을 그대로 옮겼다.

```ts
return Math.min(60 + depth * 12, 80 + era * 20)
return (chaos * plausibility) / 100
return 4 + Math.max(0, chaos - plausibility) / 4
const shardsGained = Math.floor(D / 5)
```

- 첫 줄은 새 개념의 네 스탯 합계 `T`다. 새 깊이는 두 부모 중 큰 깊이 +1이다.
- 둘째 줄은 카드에 표시되는 기본 파괴력 `D`다. 혼돈만 높고 개연이 낮으면 강하지 않다.
- 셋째 줄은 선포 때 감소하는 정합성이다. 정합성이 0 이하가 되면 백지 엔딩이다.
- 넷째 줄은 선포 보상 파편이다. 새롭고 검열되지 않은 조합 결과에는 별도로 파편 1개가 추가된다.

안정도에 적용되는 파괴력은 시대 배율을 거친다. 이어지는 값도 [`src/data/balance.ts`](../src/data/balance.ts)의 코드 그대로다.

```ts
1: 1.5,
2: 1.2,
return ERA_D_MULTIPLIER[era] ?? 1
```

제1시대는 `D × 1.5`, 제2시대는 `D × 1.2`, 제3시대 이후는 `D × 1`이 기둥 안정도에 적용된다. 정합성 감소와 선포 파편의 기준은 배율 전 `D`.

### 6.2 시대·오염·사건

- 시대 상한은 6, 시대당 선포 상한은 3이다.
- 시대를 마감하면 정합성에 8이 더해진다.
- 같은 오염 키워드가 3회 누적되면 활성 오염이 된다. 이후 API 프롬프트·폴백 생성에는 30% 확률로 오염 지시가 적용된다. 붕괴 전 하드테이블 결과의 오염 후처리도 30%지만 캐시 키를 시드로 사용해 결정적이다.
- 사건을 완료한 채 시대를 마감하면 파편 3개와 `제N시대 사건이 종결되었다.` 기록을 받는다. 미달성 페널티는 없다.
- 검열 결과 `███`를 처음 만나면 정합성 3을 회복하지만 조합·선포·복제에는 사용할 수 없다.

### 6.3 분실물 보관소

파편 10개로 수기 개념 풀에서 하나를 회수한다. 등급 확률은 등록됨 55%, 보류됨 30%, 판정불가 12%, 미분류 3%. 미분류를 뽑으면 살아 있는 기둥 하나의 안정도가 추가로 15 감소한다. 보관소 회수는 시대 사건의 발견·오염·검열 진행도에서 제외된다.

## 7. 신규 기능

### 오늘의 세계

타이틀 버튼에 KST 오늘 날짜와 시작 오염이 미리 표시된다. 날짜 시드는 기기와 세션에 무관한 초기 설정을 만들고, 같은 시드를 쓰는 사건부 과제 순서도 동일하다. 일일 저장은 일반 저장과 분리되며 날짜가 바뀌면 이어 쓰지 않는다.

### 판례 대장

카드를 클릭하면 하단에 부모 조합, 발견 시대, 당시 붕괴 수와 활성 오염, 파생 개념 최대 5개, 기둥, 기본 파괴력, 해당 개념의 연대기 문장이 표시된다. 시작 원소는 `태초부터 있었음`, 보관소 개념은 `분실물 보관소에서 회수됨`. 같은 이름을 다시 만들어도 최초 발견 계보는 덮어쓰지 않는다.

### 사건부

세계 시드로 8개 과제를 섞어 여섯 시대에 하나씩, 중복 없이 배정한다. 과제 풀은 깊이, 오염 결과 2건, 서로 다른 기둥 3곳, 파괴력 25 이상, 무붕괴, 같은 개념 심화 조합, 최초 발견 5건, 검열 1건. 완료 순간 배너가 인주색 `종결됨`으로 바뀌며 보상은 시대 마감 때 정산된다.

### 카드 복제

카드를 더블클릭하면 같은 개념의 새 인스턴스가 원본보다 x/y 각각 20px 어긋나 spring으로 등장한다. 개념을 소비하지 않고 `A + A` 심화 조합을 만들거나 여러 조합을 병렬로 준비하는 용도.

### 연대기 이미지 내보내기

엔딩 화면의 `기록 내보내기`는 클라이언트에서 만드는 1080×1920 PNG다. 엔딩 문장, 발견·붕괴·최종 시대·최고 파괴력, 긴 연대기의 앞뒤, 무너진 기둥과 규칙을 담는다. 오늘의 세계라면 날짜와 오염도 기록하며 파일명은 `uncategorized-YYYYMMDD-엔딩종류.png`.

## 8. 엔딩

| 엔딩 | 현행 조건 | 최종 문장 |
| --- | --- | --- |
| 백지 | 정합성 0 이하 | 기록할 것이 남지 않았다. |
| 무구별 | 여덟 기둥 중 6개 이상 붕괴 | 8개 범주 중 6개가 반납되었다. 남은 구별로는 당신을 오류라 부를 수 없다. |
| 분류됨 | 제6시대 마감 시 위 두 조건이 아님 | 여섯 시대가 닫혔다. 신들은 합의했다 — 당신은 이제 대장의 정식 항목이다. 예외는 더 이상 없다. |

## 9. 3분 관람 경로 (심사용)

1. 타이틀에서 **붕괴된 세계에서**를 고른다. 제4시대 사건 배너, 여덟 기둥, 이미 무너진 측정·본질과 우측 생성 규칙 2줄을 한 화면에서 살핀다.
2. 캔버스 카드 하나를 클릭해 판례 대장을 읽고 같은 카드를 더블클릭해 복제한다. 두 복제본을 겹쳐 심화 조합 실행.
3. `Tab`으로 대장을 열어 검색·정렬을 살핀다. 닫은 뒤 파편 10개로 분실물 보관소를 한 번 열고 회수한다. 보관소를 닫고 다시 `Tab`을 눌러 회수 개념을 캔버스에 꺼낸 다음, 그 카드를 클릭해 판례가 `분실물 보관소에서 회수됨`으로 표시되는지 본다.
4. 우측의 살아 있는 기둥을 고르고 카드 하나를 `ARA`에 선포한다. 신 대사, 안정도·정합성·파편 변화와 연대기 기록을 살핀다.
5. `시대 마감`으로 제5·제6시대의 서로 다른 사건 배너를 살피고 제6시대까지 마감한다. 엔딩에서 `기록 내보내기`를 눌러 PNG를 저장한다.

오늘의 세계 결정성을 먼저 보여주려면 1번에서 **오늘의 세계**를 선택해 날짜·오염 문구와 사건 배너를 확인한 뒤, 나머지 조작은 같은 순서로 진행한다. 단, 보관소를 즉시 시연하려면 파편 10개가 준비된 붕괴 데모가 더 빠르다.

## 10. 로컬 실행

Vite 8 기준 Node.js `20.19+` 또는 `22.12+`가 필요하다.

```bash
git clone https://github.com/byabbbbi/UNCATEGORIZED.git
cd UNCATEGORIZED
npm install
npm run dev
```

검증:

```bash
npm run build
npm run validate:combos
```
